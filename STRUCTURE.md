# This website, and where things go

Made with kalki.design. Keep everything in these folders, so it is always found in the same place.

| Folder | What goes in it |
| --- | --- |
| `src/app` | Pages. One folder per page, with page.tsx inside; layout.tsx for what every page shares. |
| `src/components/ui` | Building blocks used everywhere: buttons, inputs, cards. Each one matches a component on the design's Components page. |
| `src/components/sections` | Larger pieces of a page: headers, heroes, footers, pricing tables. |
| `src/styles` | The design system in code: colours, type, spacing and radii, named as on the Design System page. |
| `src/lib` | Helpers and data: fetching, formatting, anything that is not on screen. |
| `src/hooks` | Shared React hooks. |
| `public/images` | Pictures the site shows. |
| `public/icons` | Icons and logos, as SVG. |
| `public/fonts` | Font files the site ships with. |
